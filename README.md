# simulador-calado
Simulador interativo de taxa de variação do calado e curva de deslocamento (Cálculo I - Engenharia Naval/UERJ). Compara cascos prismático (taxa constante) e trapezoidal (curva não linear), exibindo o nível da linha d'água conforme o carregamento.


# Simulador de Taxa de Variação do Calado e Curva de Deslocamento

Aplicação web interativa desenvolvida para o seminário da disciplina **Cálculo I** no Curso Superior de Tecnologia em Construção Naval e de Sistemas Oceânicos (**UERJ**).

## Sobre o Projeto
O simulador aplica conceitos de derivadas e taxas de variação dT/dΔ à Arquitetura Naval, permitindo visualizar em tempo real a imersão de uma embarcação conforme o acréscimo de carga:

- **Comparação de Geometrias:** Contrasta o comportamento de um **casco prismático** (área de linha d'água constante, gerando taxa de variação linear/constante) com um **casco trapezoidal** (área variável com o calado, gerando uma curva não linear de deslocamento).
- **Visualização Hidrostática:** Ao lado do gráfico matemático, uma simulação visual acompanha a subida da linha d'água no casco conforme o peso embarcado aumenta.
- **Exemplos Práticos:** Inclui parâmetros pré-configurados de carregamento para análise rápida das curvas.

## Tecnologias
- HTML5, CSS3 e JavaScript
